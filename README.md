# TavoBridge

给 [tavo](https://tavoai.dev) 加一条「任意服务商」通道：在手机本地跑一个 OpenAI 兼容代理，
把请求转给 CodeBuddy / WorkBuddy。协议细节参考 [dsh-providers-hub](https://github.com/zhuweiyou/dsh-providers-hub)（JetHub）。
